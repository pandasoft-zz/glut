# Claude Instructions

Read [AGENTS.md](AGENTS.md) first. It is the shared instruction file for AI
coding agents in this repository.

## Commit Messages

Every commit you create must use the Conventional Commits format. See the
[Commit Messages](docs/conventions.md#commit-messages) section in Conventions
for the full specification.

Never create a commit without a conventional type prefix such as `feat:`,
`fix:`, `chore:`, `docs:`, `refactor:`, `test:`, or `ci:`.
